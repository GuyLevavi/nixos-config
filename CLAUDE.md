## Commands

```fish
rb           # sudo nixos-rebuild switch --flake /etc/nixos  — use for nixbox
             # sudo nixos-rebuild switch --flake /etc/nixos#gamingbox  — for gamingbox
update       # nix flake update --flake /etc/nixos && rb
gcold        # sudo nix-collect-garbage --delete-older-than 14d
nsh ripgrep  # temporary shell with packages (nix-shell -p)
hyprctl reload  # apply Hyprland config changes without logging out
```

```bash
# Debug a failed rebuild:
sudo nixos-rebuild switch --flake /etc/nixos#gamingbox --show-trace

# Roll back:
sudo nixos-rebuild switch --rollback

# List generations:
sudo nix-env --list-generations --profile /nix/var/nix/profiles/system
```

## Architecture

```
flake.nix                       # entry point — nixpkgs (unstable) + home-manager only
home/
  base.nix                      # headless user config — fish, zellij, git, CLI tools
  gui.nix                       # GUI layer — Hyprland WM + DMS IPC binds + apps
  airgap.nix                    # airgap/offline delta — work CLIs, pass/gpg credentials
hosts/
  common.nix                    # shared system config (boot, Hyprland+DMS+greetd, audio, nix-ld…)
  nixbox/default.nix            # Intel desktop — hostname only
  gamingbox/default.nix         # NVIDIA RTX 4060 — PRIME, Steam, CUDA + LD_LIBRARY_PATH
  */hardware-configuration.nix  # generated by nixos-generate-config; do not edit by hand
```

**Machines:** `nixbox` (Intel desktop) · `gamingbox` (NVIDIA RTX 4060 laptop).

## Critical Patterns

### Desktop: Hyprland + DankMaterialShell (DMS)

`programs.hyprland.enable = true` + `programs.dms-shell.enable = true` + `services.greetd` in `hosts/common.nix`.
Hyprland config (animations, keybinds, window rules) lives in `wayland.windowManager.hyprland.settings` in `home/gui.nix`.
DMS auto-starts via systemd — **do not** exec-once it. DMS IPC: `dms ipc call <surface> <action>`.
After editing `home/gui.nix`, run `rb` then `hyprctl reload` (or re-login).

### Shell: fish

Fish is the login shell (`users.users.gl.shell = pkgs.fish`). Shell abbreviations live in `programs.fish.shellAbbrs` in `home/base.nix`.

### Adding packages

| What | Where |
|---|---|
| User CLI app | `home.packages` in `home/base.nix` |
| User GUI app | `home.packages` in `home/gui.nix` |
| System daemon / hardware driver | `hosts/common.nix` or `hosts/<machine>/default.nix` |
| Zed LSP/formatter | `programs.zed-editor.extraPackages` in `home/gui.nix` |

### pip compiled extensions (gamingbox)

`programs.nix-ld` in `hosts/common.nix` fixes FHS entry-point binaries.
`LD_LIBRARY_PATH` in `home-manager.users.gl.home.sessionVariables` in `hosts/gamingbox/default.nix` fixes `dlopen()` for pip-installed .so files.

If a pip package fails with "libXXX.so.N not found":
  `ldd .venv/lib/python3.*/site-packages/<pkg>/*.so | grep "not found"`
Add the owning nixpkgs lib to `programs.nix-ld.libraries` and `LD_LIBRARY_PATH`.
